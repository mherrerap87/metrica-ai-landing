# Metrica AI Landing

Landing estatica para vender el diagnostico inicial de automatizacion operativa.

## Publicado

- Repo: https://github.com/mherrerap87/metrica-ai-landing
- URL provisional: https://mherrerap87.github.io/metrica-ai-landing/

## Archivos

- `index.html` - pagina principal
- `styles.css` - estilos y tokens de marca
- `script.js` - tabs y formulario de diagnostico
- `favicon.svg` - icono simple de marca

## Dominio y estado

El dominio de Metrica AI es `metricai.me`. Este repositorio GitHub Pages conserva una version historica provisional de la pagina y no representa necesariamente la web actual del dominio.

## Verificacion local

Abrir `index.html` directamente en el navegador.
